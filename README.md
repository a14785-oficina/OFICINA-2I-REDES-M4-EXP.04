# Exercício 04

Página de demonstração usando Bootstrap para elementos visuais e formulários.

## Conteúdo
- Containers e filas de layout
- Cartões com imagem e texto
- Botões estilizados
- Formulário de exemplo
- Escolha de cursos por checkbox

## Como visualizar
1. Abrir `index.html` no navegador.
2. Confirmar que a ligação CDN do Bootstrap está acessível.

## Objetivo
Introduzir componentes de layout e UI do Bootstrap, mantendo uma página estática funcional.
